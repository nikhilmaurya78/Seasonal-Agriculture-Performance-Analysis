# Seasonal Agriculture Performance Analysis

A data analytics project examining how agricultural performance varies across India's
three cropping seasons — **Kharif, Rabi, and Zaid** — using a dataset of 4,000 farm
records spanning 8 states, 10 districts, and 8 crops.

## What this project covers
- Data cleaning (missing values, duplicates, outlier checks)
- Seasonal comparison of environmental conditions (rainfall, temperature, humidity)
- Yield and production analysis with statistical significance testing (Kruskal-Wallis)
- Economic performance analysis (cost, revenue, profit, profit margin)
- Resource usage and irrigation method patterns by season
- Disease/pest risk trends
- Correlation analysis between environmental, input, and outcome variables
- Regional (state-wise) seasonal patterns
- Detection of unusual patterns (e.g. high-yield, low-profit farms)
- Data-driven recommendations for seasonal agricultural planning

## Tech stack
Python · Pandas · NumPy · Matplotlib · Seaborn · SciPy · Jupyter/Google Colab

## Key findings
- Seasonal differences in yield and profit are statistically significant (p < 0.05)
- Kharif has the highest share of profitable farms (57.8%); Zaid the lowest (35.5%)
- High yield does not guarantee profitability — 5.2% of farms had top-quartile yield but negative profit
